# Rosary narration — recording script (kok)

Read each block below aloud and save it as an audio file with the exact filename shown, then drop it into `public/audio/kok/` (replacing whatever is there now) — no code changes needed.

## Recording tips

- Use the same device/microphone and the same quiet room for every clip, so they all match in tone and background noise.
- Sit at a consistent distance from the mic; a calm, unhurried, reverent pace suits a prayer app better than a fast, neutral reading voice.
- Leave a beat of silence before and after each recording, then trim it down to a small, even pad (e.g. ~0.3s) on both ends — most voice recorder/editing apps (Voice Memos + a trim, GarageBand, Audacity) can do this.
- Export as `.mp3`. Keep every clip at a similar loudness (most editors have a "normalize" option) so nothing in the sequence suddenly sounds louder or quieter.
- `ourFather`, `hailMary`, and `gloryBe` are each recorded **once** and reused everywhere they appear (the opening prayers and every decade) — you don't need separate versions for each repetition.
- Order below follows the actual Rosary sequence, so reading straight down the list is the same order you'll pray it in.

Sotman’tam Povitr Atmeak, Katolik Povitr Sobhek, bhoktancho ektar, patkanchem bhogsonnem, kuddichem jivontponn, sasnnachem jivit. Amen.
